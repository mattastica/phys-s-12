Week 4: Programming

Sensor-Based Interlocking Tiles

Below is video from a software prototype of my first project idea, Melodia, a physical tile-based music strategy and learning game. The LEDs blink where the valid tile placements can occur. The tiles magnetically interlock, and upon sensing interlock the LED stops blinking.

Define Prototype

Two boards that connect and at least one LED that indicates connection status.

Goals

  • Use breadboard as tiles
  • Two tiles can magnetically interlock on a side
  • A non-interlocked tile will blink an LED to indicate a side that can be connected
  • Interlocked tiles will have a solid LED (opposite of game, but easier to identify)
  • Try to develop locking and sensing mechanisms using lab components

Sense Connection

The idea is to have a face of two boards have opposing magnet and hall effect sensor.

  • Digital 3144 series hall effect
  • Direct magnet, mounted on board somehow

Magnetically Interlock

The idea here is that interlock will occur through magnetic attraction. The sketch shows orientation of halls and magnets, but also how a multi-board arrangement might look. The asymmetry assures pairs.

Considerations

  • Interlock magnetics will be independent of connection sensing magnetics
  • Must ensure magnetic radiation from interlock magnet on a non-connected board doesn't trigger its connection sensor (i.e. no false-positive connects)
  • Need opposing magnetics or a magnetic surface for boards

Circuit Diagram & Board

  • Board only implements half the circuit diagram — originally each board was to support two connectable sides but ran out of breadboard space with the Xiao on it
  • Hall sensor requires 3.3v (VDD) and the Xiao's built-in pull-up resistor

Functional Prototype

const int HALL_SOUTH_PIN = D0;
const int LED_SOUTH_PIN = D1;

const unsigned long BLINK_INTERVAL_MS = 300;

unsigned long lastBlinkTime = 0;
bool ledState = LOW;

void setup() {
  pinMode(HALL_SOUTH_PIN, INPUT_PULLUP);
  pinMode(LED_SOUTH_PIN, OUTPUT);
}

void loop() {
  bool isConnected =
    digitalRead(HALL_SOUTH_PIN) == LOW;

  if (isConnected) {
    digitalWrite(LED_SOUTH_PIN, HIGH);
  } else {
    unsigned long now = millis();
    if (now - lastBlinkTime >= BLINK_INTERVAL_MS) {
      lastBlinkTime = now;
      // blink aka flip the light on/off!
      ledState = !ledState;
      digitalWrite(LED_SOUTH_PIN, ledState);
    }
  }
}

Raw code

Success

Hall sensor threshold is sufficient that the magnetic radiation of a strong magnet beneath it, and the connecting board's magnet, does not trigger it. Hence the blinking stops upon interlock only.
